PULSE — финальная самодостаточная сборка

1. Главный файл: index.html
2. Все резервные фотографии встроены прямо в index.html. Папка assets не нужна.
3. Поэтому на GitHub Pages можно заменить только index.html — серых пустых карточек из-за неправильных путей быть не должно.
4. Во втором разделе стоят спокойные фото без людей, которые интенсивно тренируются.
5. При наличии нормального доступа к Pexels браузер может незаметно заменить встроенные резервные фото на более качественные версии. Если Pexels недоступен — встроенные фото остаются и сайт не ломается.

Для GitHub Pages в корне репозитория должен быть один index.html.
