PULSE — полная актуальная версия сайта.

Файлы:
- index.html — весь сайт (HTML + CSS + JavaScript внутри одного файла)
- README.txt — эта инструкция

Для GitHub Pages:
1. В корне репозитория должен лежать index.html именно с таким именем.
2. Лишние index(...).html можно удалить.
3. После загрузки/замены index.html подождите 1–3 минуты.
4. Откройте сайт в новой вкладке или обновите Ctrl+F5.
